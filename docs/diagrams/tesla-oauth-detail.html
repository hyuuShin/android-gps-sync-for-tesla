로그인·MFA는 Tesla 화면에서 진행합니다. Tesla는 브라우저를 callback으로 보냅니다. Cloudflare의 쿠키는 Tesla 도메인으로 전달되지 않습니다.

8번 JSON → 9번 HTML → 10번 앱 저장

Tesla 응답 전체는 JSON입니다. Access Token 문자열의 JWT 구조와는 구분합니다.
Worker는 expires_at = 현재 epoch 밀리초 + expires_in × 1000을 계산합니다.
토큰 묶음을 HTML의 textarea에 표시하고, 사용자가 복사하여 앱에 저장합니다.

실패 경로: 설정 누락 503 · callback 검증 실패 400 · 토큰 교환 실패 502.
저장 이후 Android가 직접 Tesla에 차량 조회와 토큰 갱신을 요청합니다.

파랑: HTTPS 요청·응답 · 주황: 단계의 주요 전달 · 점선: 응답
로컬 글꼴 사용; 미설치 글꼴은 시스템 한국어 글꼴로 대체됩니다. 실제 토큰·Secret은 포함하지 않았습니다.
